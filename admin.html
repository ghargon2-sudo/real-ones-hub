Real Ones Admin

Commissioner-only dues tracker. Not linked from the public hub — bookmark this page.

GitHub access

Paste a GitHub personal access token with write access to ghargon2-sudo/real-ones-hub. It's stored only in this browser (localStorage) and sent only to GitHub's API — never saved anywhere else. Create a fine-grained token scoped to just this repo, with Contents: Read and write.

Dues — who's paid

Teams are pulled from ESPN. Toggle a team once their payment is in, then hit Publish. Only the dues are changed — records, scores and transactions stay owned by the sync.
